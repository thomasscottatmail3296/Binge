# Binge

Binge is an Obsidian media library and database built for accurate, scalable organization of television, films, documentaries, shorts, specials, franchises, collections, and supporting research.

## Current state

This repository was initialized from scratch as the canonical working vault. No legacy media structure, templates, plugin configuration, or historical vault files were migrated.

## Core rules

- Every episode has its own canonical folder and Markdown note.
- Movies remain standalone media and are not forced into episode structures.
- Franchises, universes, collections, indexes, and navigation pages are organizational records, not automatically media.
- Supporting assets are kept with their parent media and are only created when actually needed.
- Metadata is verified where possible; speculative records are not created.
- Structural changes are validated and recorded in **08 - Dev Log**.
- Meaningful work is committed to GitHub in logical batches.

See **Directory/Directory.md** for vault navigation and **07 - Data/Build Manifest.json** for machine-readable build state.
